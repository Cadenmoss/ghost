Set up your phone

Point the iPhone camera at a code below, then tap the banner.

Then: make it an app
  1. The key is saved — next time the plain address works.
  2. Tap Share → Add to Home Screen. You get a ghost icon that opens full-screen with no Safari chrome — it behaves like an app.
  3. Tap Connect, then tap the map and Teleport here.
Alternative: install a profile
  1. Scan the code below instead. Safari downloads a configuration profile.
  2. Open Settings → Profile Downloaded → Install.
  3. Same icon, same result — but it installs a configuration profile, so "Add to Home Screen" above is the lighter option.
